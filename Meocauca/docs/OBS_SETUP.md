# Streaming setup — OBS & TikTok LIVE Studio

Start the game first with `start.bat` (the server must stay running during the LIVE).

## OBS Studio

1. **Settings → Video**: Base (Canvas) Resolution `1080x1920`, Output (Scaled) Resolution `1080x1920`, FPS `60` (or `30`).
2. **Settings → Advanced → Sources**: make sure **Browser Source Hardware Acceleration** is enabled (needed for smooth WebGL).
3. In your scene: **Sources → + → Browser**
   - URL: `http://localhost:3000/overlay`
   - Width `1080`, Height `1920`
   - ✅ *Use custom frame rate* → `60`
   - ❌ *Shutdown source when not visible* (keep it running so animations stay in sync)
   - ✅ *Control audio via OBS* — the overlay plays the built-in lo-fi background music; this routes it into your stream mix
     (adjust it in OBS's Audio Mixer, or in *Admin → 🎮 Điều khiển → 🎵 Nhạc nền*)
   - Custom CSS (default is fine): `body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }`
4. Right-click the source → **Transform → Fit to screen**.

### Overlay URL options

| URL | Result |
|---|---|
| `/overlay` | Full game (sky, island, pond, HUD) at native 1080×1920 |
| `/overlay?bg=transparent` | Transparent page; sky + far background hidden — put your camera/background behind it |
| `/overlay?hud=0` | 3D scene only, no HUD |
| `/overlay?fps=30` | Cap to 30 FPS (weaker PCs) |
| `/overlay?quality=low` | Fewer props, no shadows, lower resolution |
| `/overlay?fit=1` | Fit to window instead of native size |
| `/overlay?music=0` | No background music on this page (use when another page already plays it) |

Combine them: `/overlay?bg=transparent&fps=30`.

### Background music

The game generates its own **lo-fi chill music in code** (Web Audio API: electric piano, pad, bass, soft drums, kalimba,
vinyl crackle + pond water). There are no audio files, so there is **nothing copyrighted** — safe for TikTok LIVE.
Settings (on/off, volume, BPM, ambience, catch chimes) live in *Admin → 🎮 Điều khiển → 🎵 Nhạc nền*.

- OBS / LIVE Studio browser sources normally start audio automatically. If you capture a normal browser window of `/game`
  instead, click the page once (or press the **"🔊 Bấm để bật nhạc nền"** button) — browsers block sound until the first click.
- Press **M** on the game page to mute/unmute locally.
- Only one page should play music: if both `/game` and `/overlay` are open, add `?music=0` to one of them.

### Voice announcements

The overlay also reads events aloud (*Admin → 🔊 Giọng nói*). The audio is generated by the server (Edge Online voice,
or the offline Windows voice) and played by the page, so it goes into the stream with **Control audio via OBS** like the
music. Only one page should speak: add `?voice=0` to the other one (e.g. `/overlay?music=0&voice=0`).

## TikTok LIVE Studio

1. Switch the canvas to **Portrait / vertical (9:16)**.
2. **Add source → Link / Web page** (the name differs by version: "Link", "Web", "Browser").
3. Paste `http://localhost:3000/overlay` and set the size to `1080 × 1920`.
4. Stretch/fit the source to the full canvas.

If your LIVE Studio version has no web source, capture OBS instead (OBS Virtual Camera) or capture the `/game` window
(Game/Window capture of a browser window showing `http://localhost:3000/game`).

## Connecting to your LIVE

Open `http://localhost:3000/admin` → **🔌 Kết nối LIVE**:

- **TikTok Live Connector**: enter your TikTok username (without `@`) — you must already be LIVE — and press *Kết nối*.
- **Baltik Live Bridge / WebSocket bridge**: enter the bridge's WebSocket URL (default `ws://127.0.0.1:21213/`).
- **Mock**: always available; the Simulator tab works even while connected to a real LIVE.

Default provider / auto-connect can be set in `config/settings.json` (`live.defaultProvider`, `live.autoConnect`, `live.tiktok.username`).

## TikTok safe zone

TikTok draws its own UI (top bar, comments, gift buttons) over your stream. In **Admin → 🎮 Điều khiển → Giao diện**
adjust the *safe zone* margins and toggle **Hiện vùng an toàn** to see the red guides on `/game` and `/overlay`.
Camera FOV, angle, zoom and center offset are adjustable there too.
